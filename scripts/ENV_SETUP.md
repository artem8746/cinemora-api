# Настройка переменных окружения для синхронизации с GitLab

## Что такое переменные окружения?

Переменные окружения — это значения, которые доступны программам во время их выполнения. Они хранятся в памяти текущей сессии терминала и не сохраняются в файлах (что безопасно для секретов).

## Как установить переменные окружения

### Вариант 1: Git Bash (который вы используете)

Откройте Git Bash и выполните:

```bash
export GITLAB_PROJECT_ID="ваш-id-проекта"
export GITLAB_ACCESS_TOKEN="ваш-новый-токен-с-ролью-maintainer"
```

**Важно:** Эти переменные действуют только в текущем окне терминала. Если закроете терминал — переменные исчезнут.

### Вариант 2: Сделать переменные постоянными (рекомендуется)

Чтобы не вводить переменные каждый раз, добавьте их в файл `~/.bashrc` или `~/.bash_profile`:

1. Откройте файл в редакторе:
   ```bash
   nano ~/.bashrc
   ```
   или
   ```bash
   code ~/.bashrc  # если используете VS Code
   ```

2. Добавьте в конец файла:
   ```bash
   # GitLab Environment Sync
   export GITLAB_PROJECT_ID="ваш-id-проекта"
   export GITLAB_ACCESS_TOKEN="ваш-новый-токен-с-ролью-maintainer"
   ```

3. Сохраните файл и перезагрузите настройки:
   ```bash
   source ~/.bashrc
   ```

Теперь переменные будут доступны во всех новых сессиях Git Bash.

### Вариант 3: Windows PowerShell

Если используете PowerShell:

```powershell
$env:GITLAB_PROJECT_ID="ваш-id-проекта"
$env:GITLAB_ACCESS_TOKEN="ваш-новый-токен-с-ролью-maintainer"
```

Для постоянного хранения в PowerShell создайте профиль:
```powershell
notepad $PROFILE
```

И добавьте:
```powershell
$env:GITLAB_PROJECT_ID="ваш-id-проекта"
$env:GITLAB_ACCESS_TOKEN="ваш-новый-токен-с-ролью-maintainer"
```

### Вариант 4: Windows CMD

Если используете обычную командную строку Windows:

```cmd
set GITLAB_PROJECT_ID=ваш-id-проекта
set GITLAB_ACCESS_TOKEN=ваш-новый-токен-с-ролью-maintainer
```

## Проверка, что переменные установлены

В Git Bash выполните:

```bash
echo $GITLAB_PROJECT_ID
echo $GITLAB_ACCESS_TOKEN
```

Должны увидеть ваши значения.

## Использование

После установки переменных просто запустите:

```bash
npm run env:sync
```

Скрипт автоматически подхватит значения из переменных окружения.

## Безопасность

⚠️ **Важно:**
- Никогда не коммитьте токены в Git
- Не добавляйте токены в файлы проекта
- Используйте переменные окружения или `.env` файлы (которые в `.gitignore`)
- Если токен скомпрометирован — отзовите его в GitLab и создайте новый

## Альтернатива: .env файл (для локальной разработки)

Можно создать файл `.env.local` (он уже в `.gitignore`):

```bash
# .env.local
GITLAB_PROJECT_ID=ваш-id-проекта
GITLAB_ACCESS_TOKEN=ваш-токен
```

Но для этого нужно будет использовать библиотеку `dotenv` для загрузки переменных. Текущий скрипт использует системные переменные окружения.
